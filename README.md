# 🩸 Blood Bank System

A responsive web-based Blood Bank System developed using **HTML, CSS, and JavaScript**. The platform is designed to bridge the gap between blood donors and recipients by providing information about blood donation, donor registration, blood availability, and healthcare services through an intuitive user interface.

## 🚀 Features

- 🩸 Blood donor registration page
- 🔍 Search blood availability based on blood group
- ❤️ Blood donation awareness and information
- 🏥 Healthcare service information
- 📱 Responsive design for desktop and mobile devices
- 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 Project Overview

The Blood Bank System is a healthcare web platform that helps connect blood donors with recipients by providing blood donation information, donor registration, and blood availability details. The application is designed to promote voluntary blood donation and provide quick access to blood-related resources during emergencies.
